title: "Export proxy ra file"

---

`POST /api/v2/customer/proxy/export`

Tạo nội dung danh sách proxy đã chọn theo format mong muốn, dùng cho việc
download file `.txt` hoặc kèm vào email cho khách.

**Áp dụng cho**: Mọi family Proxy có `capabilities.export.can = true`
**Auth**: Bearer token
**Rate limit**: Không có

## Request

### Body parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `order_ids[]` | array of integer | có (nếu không có `proxy_ids`) | Export toàn bộ proxy trong các đơn này. |
| `proxy_ids[]` | array of integer | có (nếu không có `order_ids`) | Export đúng các proxy đã chọn. |
| `type` | enum | không | `standard` (ip:port:user:pass), `authentication`, `authentication_2`, `protocol`. Mặc định `standard`. |
| `protocol` | string | không | Lọc theo protocol cụ thể (vd `socks5`). |

<Info>
Phải có ít nhất một trong `order_ids[]` hoặc `proxy_ids[]`.
</Info>

### Ví dụ

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/proxy/export' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{
    "order_ids": [1234, 1235],
    "type": "standard"
  }'
```

## Response thành công

API v2 trả về **envelope JSON** chứa text content (khác với v1 trả `Content-Disposition: attachment`). Frontend tự download:

```json
{
  "success": true,
  "message": "OK",
  "code": "ok",
  "data": {
    "content": "203.0.113.45:8080:u_AbC:p_XyZ\n203.0.113.46:8080:u_AbC:p_XyZ\n...",
    "content_type": "text/plain"
  },
  "meta": {}
}
```

Phía client convert thành file:

```js
const { data } = await callApi('/customer/proxy/export', {
  method: 'POST',
  body: JSON.stringify({ order_ids: [1234], type: 'standard' }),
});

const blob = new Blob([data.content], { type: data.content_type });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'proxies.txt';
a.click();
```

## Format

| `type` | Mỗi dòng |
|---|---|
| `standard` | `ip:port:username:password` |
| `authentication` | `username:password@ip:port` |
| `authentication_2` | `username:password:ip:port` |
| `protocol` | `protocol://username:password@ip:port` |

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | Thiếu cả `order_ids` và `proxy_ids`. |
| 403 | `forbidden` | Trong list có order/proxy không thuộc user. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- Mỗi lần export sẽ ghi vào activity log (xem [`/histories/activities`](/histories/activities)).
