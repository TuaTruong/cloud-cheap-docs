`POST /api/v2/customer/proxy/generate-bandwidth-proxies`

Sinh ra một danh sách proxy mới từ pool theo cấu hình bạn yêu cầu (quốc gia,
ASN, sticky/rotating, …) cho một gói **Proxy Bandwidth (GB)** đã mua. Mỗi
lần gọi tạo ra một tập proxy độc lập — phù hợp khi reseller cần phát hành
proxy mới cho khách hàng cuối hoặc làm rotation thủ công.

**Áp dụng cho**: Proxy có `capabilities.bandwidth_package.is_bandwidth = true`
**Auth**: Bearer token (xem [Authentication](/authentication))
**Rate limit**: Không có (mặc định)

## Khi nào dùng

- Bạn đã mua gói GB và muốn cấp một loạt proxy cho khách hàng cuối.
- Sau khi đổi filter (vd đổi quốc gia mục tiêu), cần generate lại pool.
- Tạo session sticky mới với `proxy_sticky_times` cho campaign cụ thể.

## Request

### Headers

| Header | Bắt buộc | Giá trị mẫu |
|---|---|---|
| `Authorization` | có | `Bearer 1\|abc...` |
| `Content-Type` | có | `application/json` |
| `Accept` | nên có | `application/json` |

### Body parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `proxy_id` | integer | có | ID gói bandwidth của bạn (lấy từ `customer/proxy/list`). |
| `order_number` | string | có | Mã đơn hàng chứa gói bandwidth. |
| `country_code` | string (ISO-2) | không | Lọc theo quốc gia, vd `"US"`, `"VN"`. |
| `state_code` | string | không | Lọc theo tỉnh/bang. |
| `city_code` | string | không | Lọc theo thành phố. |
| `asn_code` | string | không | Lọc theo ASN (vd `"7922"`). |
| `proxy_type` | enum `rotating` \| `sticky` | không | Mặc định `rotating`. |
| `session` | string (1–64 chars) | không | Session ID khi `proxy_type=sticky`. Tự sinh nếu trống. |
| `proxy_sticky_times` | integer (1–120) | có nếu `proxy_type=sticky` | Số **phút** giữ IP trước khi đổi. |
| `number_proxy` | integer (1–1000) | không | Số proxy muốn sinh. Mặc định `20`. |

<Info>
Filter (`country_code`, `asn_code`, …) phải lấy từ
[`bandwidth-config-options`](/proxy/bandwidth/config-options) trước khi gọi
endpoint này. Filter không hợp lệ sẽ trả về danh sách rỗng (không lỗi).
</Info>

## Response thành công

### Schema

| Field | Kiểu | Mô tả |
|---|---|---|
| `data.proxies` | array | Danh sách proxy sinh ra. |
| `data.proxies[].public_ip` | string | IP công khai cấp cho proxy. |
| `data.proxies[].port` | integer | Cổng truy cập (thường 8080 hoặc 1080). |
| `data.proxies[].username` | string | Username xác thực Basic Auth. |
| `data.proxies[].password` | string | Mật khẩu xác thực. |
| `data.proxies[].protocol` | string | `"http"` hoặc `"socks5"`. |
| `data.proxies[].session` | string \| null | Session ID khi sticky, `null` khi rotating. |
| `data.proxies[].sticky_until` | ISO datetime \| null | Thời điểm session hết hiệu lực (sticky). |
| `data.summary.requested` | integer | Số proxy yêu cầu. |
| `data.summary.generated` | integer | Số proxy thực tế tạo được. |

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | Thiếu `proxy_id`/`order_number`, hoặc `proxy_type=sticky` mà không có `proxy_sticky_times`. Chi tiết tại `errors`. |
| 403 | `forbidden` | `order_number` không thuộc về user token đang dùng. |
| 422 | `feature_unavailable` | Proxy không phải gói bandwidth (`capabilities.bandwidth_package.is_bandwidth = false`). |
| 503 | `internal_error` | Provider phía sau từ chối hoặc timeout. Có thể retry sau 30s. |

## Business notes

- Mỗi lần gọi sinh **tối đa 1000 proxy** (`number_proxy`).
- Proxy sinh ra **không trừ trực tiếp** vào quota GB — chỉ trừ khi proxy thực sự truyền dữ liệu.
- Mỗi lần gọi **tạo session mới** — proxy cũ vẫn dùng được tới khi `sticky_until` hết hạn (đối với sticky).
- Filter (`country_code`, `asn_code`, …) phải hợp lệ với pool. Lấy danh sách hợp lệ từ [`bandwidth-config-options`](/proxy/bandwidth/config-options) trước.
- Khi `proxy_type=rotating`, mỗi request từ proxy sẽ có IP khác. `proxy_sticky_times` bị bỏ qua.
