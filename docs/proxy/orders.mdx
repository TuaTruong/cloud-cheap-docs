`GET /api/v2/customer/proxy/orders`

Lấy danh sách đơn proxy đã mua. Khác với [`/proxy/list`](/proxy/list)
(liệt kê từng proxy), endpoint này liệt kê **đơn hàng** — mỗi đơn có thể
chứa nhiều proxy.

**Áp dụng cho**: Mọi group Proxy
**Auth**: Bearer token
**Rate limit**: Không có

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `page` | integer | không | Trang. Mặc định `1`. |
| `per_page` | integer | không | Số đơn mỗi trang. Mặc định `10`. |
| `search` | string | không | Tìm theo `order_number` hoặc `plan`. |
| `status` | string | không | Lọc theo user_status (vd `active`, `expired`, `cancelled`). Mặc định trả mọi trạng thái khi qua API. |

### Ví dụ

```bash
curl 'https://app.cloud-cheap.com/api/v2/customer/proxy/orders?status=active&per_page=10' \
  -H 'Authorization: Bearer 1|...'
```

## Response thành công

### Schema

Mỗi order:

| Field | Kiểu | Mô tả |
|---|---|---|
| `id` | integer | Order ID. |
| `order_number` | string | Mã đơn (vd `"ORD-PROXY-001"`). |
| `quantity` | integer | Số proxy trong đơn. |
| `price` | number | Tổng tiền đơn (VND). |
| `group` / `group_code` | string | Group của plan trong đơn. |
| `user_status` | string | `pending`, `active`, `expired`, `cancelled`, … |
| `period` | string | Vd `30 ngày`, hoặc `100 GB`. |
| `user_notes` | string \| null | Ghi chú của user cho đơn. |
| `coupon_code` | string \| null | Coupon đã dùng. |
| `discount` | number | Số tiền giảm. |
| `paid_at` | ISO datetime \| null | Thời điểm thanh toán. |
| `expired_at` | ISO datetime \| null | Hạn đơn. |
| `created_at` | ISO datetime | Tạo đơn. |
| `auto_renew` | boolean | Đơn có auto-renew không. |

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 401 | `unauthenticated` | Token sai. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- Field nội bộ `provider`, `cost_price`, `profit`, `admin_notes`, `provider_response`, `provider_extra`, `internal_extra` **không** trả ra.
- Để lấy danh sách proxy thuộc đơn → dùng [`/proxy/list?order_id=...`](/proxy/list).
