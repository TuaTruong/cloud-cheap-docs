`POST /api/v2/customer/proxy/cancel-order`

Huỷ một đơn proxy. Đơn sẽ chuyển trạng thái sang `cancelled`. Hành vi
hoàn tiền tuỳ chính sách (xem business notes).

**Áp dụng cho**: Mọi family Proxy
**Auth**: Bearer token
**Rate limit**: Không có

## Request

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `order_id` | integer | có | ID đơn cần huỷ. Phải thuộc user. |

### Ví dụ

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/proxy/cancel-order' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{ "order_id": 1234 }'
```

## Response thành công

```json
{
  "success": true,
  "message": "Huỷ đơn thành công",
  "code": "ok",
  "data": {
    "order_id": 1234,
    "status": "cancelled",
    "refunded": 0
  },
  "meta": {}
}
```

| Field | Mô tả |
|---|---|
| `refunded` | Số tiền hoàn về `balance` (nếu có chính sách hoàn). Thường = `0`. |

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | `order_id` không thuộc user. |
| 422 | `validation_failed` | Đơn đã `cancelled` hoặc `expired` — không huỷ thêm được. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- Đơn sau huỷ vẫn xuất hiện trong [`/proxy/orders`](/proxy/orders) với `user_status = cancelled` — để audit.
- Proxy trong đơn sẽ bị **vô hiệu hoá ngay lập tức** — không thể dùng dù còn hạn.
- Chính sách hoàn tiền tuỳ admin config. Liên hệ support nếu cần hoàn.
- Sau huỷ, **không thể** undo. Cần xác nhận phía UI.
