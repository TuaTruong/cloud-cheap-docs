`POST /api/v2/customer/vps/cancel-order`

Huỷ một đơn VPS. VPS trong đơn sẽ bị provider terminate ngay lập tức —
mọi data trên VPS sẽ bị xoá.

**Auth**: Bearer token

<Warning>
**Không thể hoàn tác**. Data trên VPS sẽ bị xoá ngay khi terminate. Backup
trước nếu cần.
</Warning>

## Request

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `order_id` | integer | có | ID đơn VPS cần huỷ (phải thuộc user). |

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/vps/cancel-order' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{ "order_id": 5001 }'
```

## Response thành công

```json
{
  "success": true,
  "message": "Huỷ đơn VPS thành công",
  "code": "ok",
  "data": {
    "order_id": 5001,
    "status": "cancelled",
    "refunded": 0
  },
  "meta": {}
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | `order_id` không thuộc user, hoặc đã cancelled/expired. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- Chính sách hoàn tiền tuỳ admin config — thường = `0`.
- VPS bị mark `cancelled`, vẫn hiển thị trong [`/vps/orders?status=cancelled`](/vps/orders) để audit.
- Hành động ghi vào [activity log](/histories/activities).
