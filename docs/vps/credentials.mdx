title: "Lấy credentials VPS"
description: "Lấy username + root password hiện tại"
---

`POST /api/v2/customer/vps/credentials`

Lấy thông tin đăng nhập của VPS (username + root password). Phía UI
nên có flow "Click to reveal" + warning về bảo mật.

<Warning>
**Chỉ áp dụng cho VPS có `capabilities.credentials.can = true`**.
</Warning>

**Auth**: Bearer token

## Request

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `id` | integer | có | VPS ID (phải thuộc user). |

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/vps/credentials' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{ "id": 4567 }'
```

## Response thành công

```json
{
  "success": true,
  "code": "ok",
  "data": {
    "vps_username": "root",
    "root_password": "AutoGenPass123!",
    "ssh_key": "ssh-rsa AAAAB3NzaC1yc2E...",
    "main_ipv4": "203.0.113.10",
    "ssh_port": 22
  },
  "meta": {}
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | `id` thiếu. |
| 403 | `forbidden` | VPS không thuộc user. |
| 422 | `feature_unavailable` | Capability không khả dụng cho VPS này (xem `capabilities`). |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- `root_password` là **password hiện tại** — đã đồng bộ với VPS.
- Nếu cần đổi password: dùng [`/vps/change-password`](/vps/change-password) (cần password cũ) hoặc [`/vps/config` action `reset_root_password`](/vps/config) (sinh password mới ngẫu nhiên).
- SSH key (nếu có) đã được provision vào `~/.ssh/authorized_keys` của user `root`.
- Endpoint **không nên call thường xuyên** — chỉ khi user click reveal trong UI.
