`GET /api/v2/customer/vps/list`

Lấy danh sách VPS user đang sở hữu. Mỗi record có `group`, `group_code`,
`capabilities` (đã áp runtime override) để UI biết hiển thị nút nào.

**Áp dụng cho**: Mọi group VPS
**Auth**: Bearer token

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `page` | integer | không | Trang. Mặc định `1`. |
| `per_page` | integer (1–100) | không | Số record mỗi trang. Mặc định `10`. |
| `order_id` | integer | không | Lọc theo 1 đơn. |
| `search` | string | không | Tìm theo `hostname` / `main_ipv4`. |
| `status` | string | không | Lọc theo trạng thái (`active`, `expired`, `provisioning`, …). |

```bash
curl 'https://cloud-cheap.com/api/v2/customer/vps/list?per_page=20&status=active' \
  -H 'Authorization: Bearer 1|...'
```

## Response thành công

### Schema

Mỗi VPS record:

| Field | Kiểu | Mô tả |
|---|---|---|
| `id` | integer | VPS ID. |
| `group` / `group_code` | string | Group hiển thị + code (xem [Product families](/concepts/product-groups)). |
| `hostname` | string | Hostname VPS. |
| `os_type` / `os_version` | string | Hệ điều hành đang chạy. |
| `period` | string | Chu kỳ thanh toán (`monthly`, `quarterly`, …). |
| `price` | number | Giá bán cho khách (VND). |
| `status` | string | `active`, `expired`, `provisioning`, `suspended`. |
| `action_status` | string \| null | Action đang chạy (`reinstalling`, `upgrading`, …). |
| `config.cpu` / `config.ram` / `config.disk` | integer | Cấu hình hiện tại. |
| `config.bandwidth_mbps` | integer | Tốc độ network (Mbps). |
| `location` | string | Vị trí datacenter (vd `"Việt Nam - FPT"`). |
| `main_ipv4` | string | IP chính. |
| `ipv4_addresses[]` | array | Tất cả IPv4. |
| `ipv6_addresses[]` | array | Tất cả IPv6. |
| `ipv6_subnets[]` | array | IPv6 subnet (nếu có). |
| `vps_username` | string | User SSH. |
| `actions[]` | string[] | List action khả dụng runtime (vd `["power_on","reboot","reinstall_current_os"]`). |
| `expired_at` | ISO datetime | Hạn dùng. |
| `auto_extend` | boolean | Bật auto-renew? |
| `is_auto_renewing` | boolean | Đang trong quá trình renew? |
| `notes` | string \| null | Ghi chú của user. |
| `capabilities` | object | 9 capability flag (xem [Capabilities](/concepts/capabilities)). |

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 401 | `unauthenticated` | Token sai. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- `provider`, `provider_vps_id`, `cost_price`, `provider_response`, `internal_extra`, `provider_extra` **không** trả ra.
- `root_password` xuất hiện trong field này nhưng nên **không hiển thị mặc định** trên UI — yêu cầu user click "Show" mới reveal.
- `actions[]` tính runtime — chỉ chứa các action thực sự có thể chạy ngay (vd VPS đang `provisioning` → `actions = []`).
- `capabilities` đã áp runtime override (vd `console.can = false` nếu VPS thiếu `main_ipv4`).
