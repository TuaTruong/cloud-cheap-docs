`POST /api/v2/customer/vps/transfer-to-another-user`

Chuyển một hoặc nhiều VPS sang user khác (cùng hệ thống). Sau khi
transfer, bạn không còn quyền điều khiển VPS đó.

**Auth**: Bearer token

## Request

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `vps_ids[]` | array of integer | có | ID các VPS cần chuyển. |
| `email` | string (email) | có | Email user nhận. Phải tồn tại. |

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/vps/transfer-to-another-user' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{
    "vps_ids": [4567, 4568],
    "email": "newowner@example.com"
  }'
```

## Response thành công

```json
{
  "success": true,
  "message": "Chuyển VPS thành công",
  "code": "ok",
  "data": {
    "transferred": [4567, 4568],
    "new_owner_email": "newowner@example.com"
  },
  "meta": {}
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | Email không tồn tại, hoặc VPS không thuộc user. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- **Không thể hoàn tác**.
- VPS giữ nguyên IP, cấu hình, password, hostname — chỉ đổi `user_id`.
- Cả 2 user nhận email thông báo.
- Hành động ghi vào activity log của cả 2 user.
