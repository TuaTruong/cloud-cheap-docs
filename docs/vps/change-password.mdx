---
title: "Đổi root password VPS"
description: "Đổi password VPS đang chạy — không reinstall"
---

`POST /api/v2/customer/vps/change-password`

Đổi root password trực tiếp trên VPS đang chạy. Không cần reinstall —
VPS không bị restart.

<Warning>
**Chỉ áp dụng cho VPS có `capabilities.change_password.can = true`**.
Khác với `config` action `reset_root_password`: endpoint này cần
password cũ + không reinstall.
</Warning>

**Auth**: Bearer token

## Request

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `id` | integer | có | VPS ID. |
| `username` | string | có | User cần đổi (thường `root`). |
| `old_password` | string | có | Password hiện tại để xác minh. |
| `new_password` | string (≥8) | có | Password mới. Yêu cầu: 1 hoa + 1 thường + 1 số + 1 ký tự đặc biệt. |

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/vps/change-password' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{
    "id": 4567,
    "username": "root",
    "old_password": "OldPass123!",
    "new_password": "NewSecure456@"
  }'
```

## Response thành công

```json
{
  "success": true,
  "message": "Đổi password thành công",
  "code": "ok",
  "data": {
    "id": 4567,
    "vps_username": "root",
    "main_ipv4": "203.0.113.10"
  },
  "meta": {}
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | Param thiếu hoặc password không đủ độ phức tạp. |
| 403 | `forbidden` | VPS không thuộc user. |
| 422 | `feature_unavailable` | Capability không khả dụng cho VPS này (xem `capabilities`). |
| 200 | `request_failed` | `old_password` sai, hoặc hệ thống từ chối. |
| 500 | `internal_error` | Lỗi server. |

### Ví dụ — sai password cũ

```json
{
  "success": false,
  "message": "Password hiện tại không đúng",
  "code": "request_failed",
  "errors": {},
  "meta": {}
}
```

## Business notes

- Endpoint **không reinstall** — VPS giữ nguyên state, không mất data.
- Cần password cũ → an toàn hơn `reset_root_password` (không cần password cũ nhưng phải reinstall).
- Nếu quên password cũ, dùng [`/vps/config` action `reset_root_password`](/vps/config) (reinstall).
- Sau đổi, [`/vps/credentials`](/vps/credentials) sẽ trả password mới.

## So sánh các phương án đổi password

| Endpoint | Cần password cũ | Reinstall | Phù hợp |
|---|---|---|---|
| [`/vps/change-password`](/vps/change-password) | ✅ Có | ❌ Không | Đổi password định kỳ, biết password cũ |
| [`/vps/config` `reset_root_password`](/vps/config) | ❌ Không | ✅ Có | Quên password, chấp nhận reinstall |
| [`/vps/config` `set_root_password`](/vps/config) | ❌ Không | ✅ Có | Đặt password chỉ định, chấp nhận reinstall |
