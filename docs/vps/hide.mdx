`POST /api/v2/customer/vps/hide`

Set `hidden_at` cho VPS để không hiển thị trong danh sách mặc định
(`/vps/list`). VPS **vẫn hoạt động bình thường** — đây chỉ là UI flag.

**Auth**: Bearer token

## Request

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `id` | integer | có | VPS ID (phải thuộc user). |
| `hidden` | boolean | có | `true` = ẩn, `false` = bỏ ẩn. |

```bash
curl -X POST 'https://cloud-cheap.com/api/v2/customer/vps/hide' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Content-Type: application/json' \
  -d '{ "id": 4567, "hidden": true }'
```

## Response thành công

```json
{
  "success": true,
  "message": "Đã ẩn VPS",
  "code": "ok",
  "data": {
    "id": 4567,
    "hidden_at": "2026-05-18T10:30:00Z"
  },
  "meta": {}
}
```

Khi `hidden=false`:

```json
{
  "data": { "id": 4567, "hidden_at": null }
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | `id` không thuộc user. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- VPS bị ẩn **vẫn tiếp tục tính phí** + chạy bình thường.
- Để xem VPS bị ẩn: gọi [`/vps/list?show_hidden=true`](/vps/list) (nếu hỗ trợ) hoặc lọc theo `hidden_at != null` phía client.
- Đây là feature UX, không phải security — không nên dùng để giấu data nhạy cảm.
- Nếu muốn xoá VPS hoàn toàn, dùng [`/vps/cancel`](/vps/cancel).
