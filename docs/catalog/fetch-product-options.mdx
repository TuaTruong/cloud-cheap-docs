`GET /api/v2/fetch-product-options`

Khi customer chọn một plan trong catalog, bạn gọi endpoint này để lấy
các tuỳ chọn động (region, OS, protocol, price components, …). Dữ liệu
trả về dùng để render form mua hàng phía UI.

**Áp dụng cho**: Mọi group (Proxy + VPS)
**Auth**: Không bắt buộc
**Rate limit**: Không có

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `plan_id` | integer | có | ID plan lấy từ `fetch-proxy-products` / `fetch-vps-products`. |
| `vps_id` | integer | không | Chỉ áp dụng khi gọi cho VPS đã tồn tại (vd lấy options upgrade). |

### Ví dụ

```bash
curl 'https://app.cloud-cheap.com/api/v2/fetch-product-options?plan_id=12' \
  -H 'Accept: application/json'
```

## Response thành công

### Schema chung

Cấu trúc `data` phụ thuộc loại plan. Hai khối lớn:

**Cho Proxy plan**: `data` chứa `regions`, `protocols`, `days`, `auth_types`, `price_components`, …

**Cho VPS plan**: `data` chứa `os`, `regions` (hoặc `locations`), `cpu_options`, `ram_options`, `disk_options`, `bandwidth_options`, `price_components`, …

### Ví dụ — Proxy plan

```json
{
  "success": true,
  "message": "Success",
  "code": "ok",
  "data": {
    "regions": ["US", "VN", "SG", "DE"],
    "protocols": { "http": "HTTP", "socks5": "SOCKS5" },
    "days": { "min": 7, "max": 365, "step": 1 },
    "auth_types": ["user_pass"],
    "price_components": {
      "base_per_day": 50000,
      "discount_tiers": [
        { "min_days": 30, "discount_percent": 5 },
        { "min_days": 90, "discount_percent": 15 }
      ]
    }
  },
  "meta": {}
}
```

### Ví dụ — VPS plan

```json
{
  "success": true,
  "message": "Success",
  "code": "ok",
  "data": {
    "os": [
      { "id": "ubuntu-22", "name": "Ubuntu 22.04 LTS" },
      { "id": "win-2022", "name": "Windows Server 2022" }
    ],
    "locations": [
      { "id": "vn-fpt", "name": "Việt Nam - FPT" },
      { "id": "us-ca", "name": "California, US" }
    ],
    "cpu_options": [2, 4, 8, 16],
    "ram_options": [2, 4, 8, 16, 32],
    "disk_options": { "min": 30, "max": 240, "step": 10 },
    "bandwidth_options": [1000, 5000, 10000],
    "price_components": {
      "base": 100000,
      "addon_cpu_per_core": 20000,
      "addon_ram_per_gb": 15000,
      "addon_disk_per_gb": 1000
    }
  },
  "meta": {}
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | Thiếu `plan_id` hoặc `plan_id` không tồn tại / inactive. |
| 200 | `ok` | Plan có nhưng không có option động — `data: []`. UI dùng giá `price` từ catalog. |
| 500 | `internal_error` | Lỗi server. |

### Ví dụ — plan không có option động

```json
{
  "success": true,
  "message": "Empty",
  "code": "ok",
  "data": [],
  "meta": {}
}
```

## Business notes

- Một số plan **không có** option động (giá cố định, không config) → trả `data: []`.
- Cấu trúc field trong `data` khác giữa Proxy và VPS — frontend cần check `type` từ catalog trước khi parse.
- Frontend **không nên** cache response này lâu (giá có thể thay đổi runtime theo tỉ giá / khuyến mãi).
- Truyền `vps_id` chỉ khi customer đang chọn upgrade cho VPS đã có.
