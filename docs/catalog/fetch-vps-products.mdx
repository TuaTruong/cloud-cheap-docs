`GET /api/v2/fetch-vps-products`

Trả về toàn bộ sản phẩm VPS đang active, **nhóm theo product family**.
Mỗi plan có sẵn `family`, `family_code` và `capabilities` mặc định.

**Áp dụng cho**: 7 family VPS — Standard, Pro, Basic, Performance, Streaming, Custom, Promo
**Auth**: Không bắt buộc
**Rate limit**: Không có

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `locale` | enum `en` \| `vi` \| `fr` \| `zh` | không | Ngôn ngữ. Mặc định `en`. |

### Ví dụ

```bash
curl 'https://cloud-cheap.com/api/v2/fetch-vps-products?locale=vi' \
  -H 'Accept: application/json'
```

## Response thành công

### Schema

Top-level `data` là array of family groups. Mỗi group:

| Field | Kiểu | Mô tả |
|---|---|---|
| `family` | string | Vd `"VPS Standard"`, `"VPS Pro"`. |
| `family_code` | string | Mã family (xem [Product families](/concepts/product-families)). |
| `plans` | array | Danh sách plan thuộc family. |

Mỗi plan:

| Field | Kiểu | Mô tả |
|---|---|---|
| `id` | integer | Plan ID. |
| `name` | string | Tên hiển thị. |
| `plan` | string | Tên ngắn. |
| `short_des` | string | Mô tả ngắn. |
| `description` | string | Mô tả dài. |
| `type` | string | `"vps"`. |
| `service_type` | string | Phân loại. |
| `price` | number | Giá hiển thị (VND). |
| `family` / `family_code` | string | (Trùng group) |
| `capabilities` | object | 9 capability flag mặc định cho family VPS. |
| `client_features.fixed_addon_pricing` | boolean | Pricing fixed cho upgrade? |
| `client_features.disk_step` | integer | Bước upgrade disk (GB) — `1` cho hầu hết, `10` cho VPS Pro. |
| `badges` | string[] | Tag marketing: `"gpu"`, `"best_seller"`, … |
| `options` | object | OS, region khả dụng. |

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 500 | `internal_error` | Lỗi server. |

## Business notes

- Chỉ trả về plan `status = 'active'`.
- Mỗi family có chính sách pricing addon khác nhau — đọc từ `client_features.fixed_addon_pricing` và `client_features.disk_step` (per-plan), **không hardcode** theo `family_code`.
- `badges` dùng để hiển thị tag marketing (vd "Best Seller", "GPU available").
- Frontend nên cache 5–15 phút.
