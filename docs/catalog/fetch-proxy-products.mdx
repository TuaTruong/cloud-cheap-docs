`GET /api/v2/fetch-proxy-products`

Trả về toàn bộ sản phẩm Proxy đang active trên hệ thống, **nhóm theo
product family**. Mỗi plan có sẵn `family`, `family_code` và
`capabilities` mặc định — bạn dùng để render catalog phía UI.

**Áp dụng cho**: Mọi family Proxy
**Auth**: Không bắt buộc
**Rate limit**: Không có

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `locale` | enum `en` \| `vi` \| `fr` \| `zh` | không | Ngôn ngữ cho `name`, `description`. Mặc định `en`. |

### Ví dụ

```bash
curl 'https://cloud-cheap.com/api/v2/fetch-proxy-products?locale=vi' \
  -H 'Accept: application/json'
```

## Response thành công

### Schema

Top-level `data` là **array of family groups**. Mỗi group:

| Field | Kiểu | Mô tả |
|---|---|---|
| `family` | string | Tên hiển thị family (vd `"Proxy IPv4 Datacenter"`). |
| `family_code` | string | Mã family (xem [Product families](/concepts/product-families)). |
| `plans` | array | Danh sách plan thuộc family này. |

Mỗi plan trong `plans`:

| Field | Kiểu | Mô tả |
|---|---|---|
| `id` | integer | Plan ID, dùng làm `plan_id` khi gọi `pay`. |
| `name` | string | Tên hiển thị (đã localize). |
| `plan` | string | Tên kỹ thuật ngắn. |
| `short_des` | string | Mô tả ngắn. |
| `description` | string | Mô tả dài (markdown). |
| `type` | string | `"proxy"`. |
| `service_type` | string | Phân loại kỹ thuật (`datacenter-ipv4`, `ipv6`, …). |
| `price` | number | Giá hiển thị (VND). |
| `price_unit` | string | `"day"`, `"month"`, `"gb"`. |
| `price_duration` | integer | Số đơn vị tương ứng. |
| `package_quantity` | integer | Số proxy mỗi gói. |
| `family` | string | (Trùng family group) |
| `family_code` | string | (Trùng family group) |
| `capabilities` | object | Capability mặc định cho family. Xem [Capabilities](/concepts/capabilities). |
| `options` | object | Options khả dụng (protocol, region, days, …). |
| `auto_renew_enabled` | boolean | Có hỗ trợ auto-renew không. |
| `is_bandwidth_plan` | boolean | Là gói bandwidth GB không (`true` cho family `proxy_bandwidth`). |

## Errors

Endpoint không có lỗi business — trường hợp xấu nhất là `data: []` (không có sản phẩm active).

| HTTP | `code` | Khi nào |
|---|---|---|
| 500 | `internal_error` | Lỗi server. Retry sau. |

## Business notes

- Chỉ trả về sản phẩm `status = 'active'`.
- Plan đã ngừng bán / loại khỏi danh mục **không xuất hiện**.
- `capabilities` ở đây là **default theo family** — record proxy thực
  tế (`customer/proxy/list`) có thể có capability khác do runtime override.
- Frontend nên cache response này 5–15 phút.
