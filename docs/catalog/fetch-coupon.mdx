`GET /api/v2/fetch-coupon`

Kiểm tra mã coupon còn hiệu lực và tính số tiền giảm cho một `grand_total`
cụ thể. Dùng trước khi gọi `pay` để hiển thị giá cuối cho khách.

**Áp dụng cho**: Mọi loại đơn hàng (Proxy / VPS)
**Auth**: Không bắt buộc (endpoint công khai)
**Rate limit**: Không có (mặc định)

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `coupon_code` | string | có | Mã coupon cần kiểm tra (case-sensitive). |
| `grand_total` | number | không | Tổng giá đơn hàng dự kiến (VND). Mặc định `0`. |

### Ví dụ

<CodeGroup>

```bash cURL
curl 'https://cloud-cheap.com/api/v2/fetch-coupon?coupon_code=WELCOME50&grand_total=200000' \
  -H 'Accept: application/json'
```

```php PHP
$url = 'https://cloud-cheap.com/api/v2/fetch-coupon?' . http_build_query([
    'coupon_code' => 'WELCOME50',
    'grand_total' => 200000,
]);

$body = file_get_contents($url);
$response = json_decode($body, true);

if ($response['success']) {
    echo "Giảm: " . $response['data']['discount'] . " VND";
}
```

</CodeGroup>

## Response thành công

### Schema

| Field | Kiểu | Mô tả |
|---|---|---|
| `data.coupon_code` | string | Mã coupon (echo lại). |
| `data.discount` | number | Số tiền được giảm cho `grand_total` đã đưa (VND). |

### Ví dụ

```json
{
  "success": true,
  "message": "OK",
  "code": "ok",
  "data": {
    "coupon_code": "WELCOME50",
    "discount": 100000
  },
  "meta": {}
}
```

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 422 | `validation_failed` | Thiếu `coupon_code`. |
| 404 | `coupon_invalid` | Mã không tồn tại / hết hạn / đã đủ lượt sử dụng. |

### Ví dụ — coupon không hợp lệ

```json
{
  "success": false,
  "message": "Coupon không hợp lệ hoặc đã hết hạn",
  "code": "coupon_invalid",
  "errors": {},
  "meta": {}
}
```

## Business notes

- `discount` được tính theo loại coupon (`fixed` hoặc `percentage`) và có
  thể bị giới hạn bởi `max_discount_amount`.
- Coupon có `min_order_amount` — nếu `grand_total` thấp hơn, `discount`
  trả về sẽ là `0`.
- Endpoint **không reserve** coupon. Bạn phải truyền lại `coupon_code` khi
  gọi `/customer/proxy/pay` hoặc `/customer/vps/pay` để áp dụng thực sự.
