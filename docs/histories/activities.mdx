`GET /api/v2/customer/histories/activities`

Trả về **audit log** của user — mọi hành động đã thực hiện trên hệ thống:
mua proxy/VPS, đổi IP, đổi auth, renew, transfer, đăng nhập, … kèm IP
address + user agent.

**Áp dụng cho**: User đã đăng nhập
**Auth**: Bearer token
**Rate limit**: Không có

## Request

### Query parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `page` | integer | không | Trang. Mặc định `1`. |
| `per_page` | integer (1–100) | không | Số bản ghi mỗi trang. Mặc định `20`. |
| `keyword` | string | không | Tìm theo `order_number`, `plan`, `email`, `vps_ip`, `proxy_ip`. |
| `date` | string `YYYY-MM-DD` | không | Lọc theo ngày tạo. |
| `sort[]` | array | không | Tabulator-style sort. |

### Ví dụ

```bash
curl 'https://app.cloud-cheap.com/api/v2/customer/histories/activities?keyword=ORD-PROXY-001' \
  -H 'Authorization: Bearer 1|...' \
  -H 'Accept: application/json'
```

## Response thành công

### Schema

| Field | Kiểu | Mô tả |
|---|---|---|
| `id` | integer | Activity ID. |
| `action_key` | string | Khoá i18n của hành động (vd `"activity_log.buy_proxy"`). |
| `note` | string | Mô tả đã localize. |
| `ip_address` | string | IP của user khi thực hiện. |
| `user_agent` | string | User agent browser/app. |
| `related_type` | string \| null | Loại object: `"proxy"`, `"proxy_order"`, `"vps"`, `"vps_order"`, `"bank_transaction"`. |
| `subject_id` | integer \| null | ID object liên quan. |
| `created_at` | ISO datetime | Thời điểm. |

`meta.pagination` giống [Payments](/histories/payments).

## Errors

| HTTP | `code` | Khi nào |
|---|---|---|
| 401 | `unauthenticated` | Token sai. |
| 500 | `internal_error` | Lỗi server. |

## Business notes

- Endpoint dành cho **audit trail** — không thể xoá hoặc sửa record.
- `note` được render với placeholders trong `action_params` (vd `:plan`, `:ip`). Nếu cần raw, dùng v1.
- `keyword` filter dùng `LOWER(JSON_EXTRACT(...))` cho field trong `action_params` — hỗ trợ tìm theo bất kỳ field nào trong note.
- Trường hợp dùng phổ biến: phía reseller portal hiển thị tab "Lịch sử" cho khách hàng cuối.
