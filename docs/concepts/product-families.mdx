## Vì sao có family?

Sản phẩm trong catalog rất nhiều SKU. Để code UI và logic giá phía bạn
gọn gàng, mỗi sản phẩm thuộc về **một family** — nhóm các sản phẩm có
cùng đặc tính kỹ thuật và surface tính năng tương tự.

Mọi response catalog (`/fetch-proxy-products`, `/fetch-vps-products`) và
mọi record proxy/VPS (`/customer/proxy/list`, `/customer/vps/list`) đều có
hai field:

| Field | Kiểu | Ví dụ |
|---|---|---|
| `family` | string | `"Proxy IPv4 Datacenter"` |
| `family_code` | string (snake_case) | `"proxy_ipv4_datacenter"` |

**`family_code` ổn định**, dùng làm khoá lookup phía code. `family` là tên
hiển thị (có thể đổi cho marketing).

## Cách dùng family

### 1. Lọc catalog theo family

```bash
curl 'https://cloud-cheap.com/api/v2/fetch-proxy-products' \
  -H 'Authorization: Bearer <token>'
```

Response group theo `family_code`:

```json
{
  "success": true,
  "data": [
    {
      "family": "Proxy IPv4 Datacenter",
      "family_code": "proxy_ipv4_datacenter",
      "plans": [
        { "id": 10, "name": "...", "price": 50000, /* ... */ }
      ]
    },
    {
      "family": "Proxy Residential Rotating",
      "family_code": "proxy_residential_rotating",
      "plans": [/* ... */]
    }
  ]
}
```

Phía UI bạn render tab theo family, gọn gàng.

### 2. Phân biệt logic theo family_code

```js
function shouldShowChangeIpButton(proxy) {
  return proxy.capabilities.change_ip.can === true;
}

function priceRangeForFamily(familyCode) {
  switch (familyCode) {
    case 'proxy_residential_static':
    case 'proxy_residential_rotating':
      return { min: 80000, max: 150000 };
    case 'proxy_ipv4_datacenter':
      return { min: 40000, max: 60000 };
    case 'proxy_bandwidth':
      return { min: 0, max: null };
    default:
      return null;
  }
}
```

### 3. Quyết định flow tích hợp

Mỗi family có flow mua + quản lý hơi khác:

- **Proxy non-bandwidth**: mua theo `quantity` × period → trả về danh sách
  proxy có `expired_at`.
- **Proxy Bandwidth**: mua theo `bandwidth_gb` → mở gói GB → **generate**
  proxy list từ pool theo nhu cầu.
- **VPS**: mua theo `period` + config → trả về 1 record VPS, sau đó có
  thể `power-control`, `config`, `upgrade`.

Mỗi flow có trang riêng trong tài liệu này.

## Lưu ý quan trọng

<Info>
Family **ổn định trong thời gian dài** nhưng có thể được bổ sung. Code
client nên dùng `switch (family_code)` với `default` xử lý fallback an
toàn (vd "Sản phẩm này chưa hỗ trợ").
</Info>

<Warning>
**Không bao giờ** parse tên brand từ `name` hoặc `plan` của sản phẩm.
Chỉ dùng `family_code` + `capabilities` để quyết định logic.
</Warning>
